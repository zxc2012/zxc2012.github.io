K-Means Clustering & its Variants​

Objective Function & Lloyd's Algorithm​

Partition NNN points into KKK clusters S={S1,S2,…,SK}S = \{S_1, S_2, \dots, S_K\}S={S1​,S2​,…,SK​} to minimize within-cluster sum of squares (Inertia):

min⁡S,μ∑i=1K∑x∈Si∥x−μi∥22\boxed{\min_{S, \mu} \sum_{i=1}^K \sum_{x \in S_i} \|x - \mu_i\|_2^2}S,μmin​i=1∑K​x∈Si​∑​∥x−μi​∥22​​

Two-step coordinate descent:

  1. Assignment step: assign each instance to its closest centroid:
    c(i)=arg⁡min⁡j∥x(i)−μj∥22c^{(i)} = \arg\min_j \|x^{(i)} - \mu_j\|_2^2c(i)=argjmin​∥x(i)−μj​∥22​
  2. Update step: recompute centroids as mean of assigned points:
    μj=∑i=1N1{c(i)=j}x(i)∑i=1N1{c(i)=j}\mu_j = \frac{\sum_{i=1}^N \mathbf{1}\{c^{(i)} = j\} x^{(i)}}{\sum_{i=1}^N \mathbf{1}\{c^{(i)} = j\}}μj​=∑i=1N​1{c(i)=j}∑i=1N​1{c(i)=j}x(i)​
def calculate_distance(point1, point2):
    return sum((x-y)**2 for x,y in zip(point1,point2))

def k_means_clustering(points: list[tuple[float, ...]], k: int, initial_centroids: list[tuple[float, ...]], max_iterations: int) -> list[tuple[float, ...]]:
    final_centroids = list(initial_centroids)
    for i in range(max_iterations):
        # 1. Assignment step
        labels = [min(range(k), key= lambda x: calculate_distance(point, initial_centroids[x])) for point in points]

        # 2. Update step
        for i in range(k):
            group = [ point for point,label in zip(points, labels) if label == i]
            if group:
                final_centroids[i] = tuple(sum(item)/len(group) for item in zip(*group))
    return final_centroids

Limitations:

  • Sensitive to centroid initialization (can get trapped in local minima).
  • Assumes spherical, equally-sized clusters with similar density.
  • Sensitive to outliers (mean is heavily affected).
  • KKK must be specified in advance.

How to Choose K​

  • Elbow Method: plot Inertia (SSE) vs KKK. Pick the "elbow" point where marginal loss reduction slows down significantly.
  • Silhouette Score: evaluates cohesion vs separation for each sample:
    s(i)=b(i)−a(i)max⁡(a(i),b(i))∈[−1,1]s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))} \in [-1, 1]s(i)=max(a(i),b(i))b(i)−a(i)​∈[−1,1]
    where a(i)a(i)a(i) is mean intra-cluster distance, b(i)b(i)b(i) is mean nearest-cluster distance. Higher is better.

Variants​

1. K-Means++​

Addresses initialization sensitivity:

  1. Choose first centroid μ1\mu_1μ1​ uniformly at random from dataset.
  2. For each point xxx, compute D(x)D(x)D(x), the shortest distance to existing centroids.
  3. Choose next centroid from points with probability:
    P(x)=D(x)2∑x′D(x′)2\boxed{P(x) = \frac{D(x)^2}{\sum_{x'} D(x')^2}}P(x)=∑x′​D(x′)2D(x)2​​
  4. Repeat steps 2-3 until KKK centroids are chosen.

Theoretical guarantee: O(log⁡K)O(\log K)O(logK)-competitive with optimal solution.

2. Mini-Batch K-Means​

Optimized for large-scale datasets:

  • Samples a mini-batch of size B≪NB \ll NB≪N at each iteration.
  • Centroids updated using online running average: μk←(1−η)μk+ηx\mu_k \leftarrow (1-\eta)\mu_k + \eta xμk​←(1−η)μk​+ηx.
  • Drastically reduces computation and memory per step with minimal quality drop.

3. K-Medoids (PAM - Partitioning Around Medoids)​

  • Centroids must be actual data points (medoids) instead of means.
  • Can minimize arbitrary dissimilarity (e.g. Manhattan L1 distance) instead of squared Euclidean:
    min⁡∑i=1K∑x∈Sid(x,mi)\min \sum_{i=1}^K \sum_{x \in S_i} d(x, m_i)mini=1∑K​x∈Si​∑​d(x,mi​)
  • Much more robust to outliers and noise than K-Means.

Principal Component Analysis (PCA)​

Linear unsupervised dimensionality reduction: find orthogonal projection directions that maximize preserved variance (equivalently, minimize reconstruction error).

Mathematical Derivation (Maximum Variance)​

Let dataset X∈RN×dX \in \mathbb{R}^{N \times d}X∈RN×d be zero-centered: ∑i=1Nx(i)=0\sum_{i=1}^N x^{(i)} = 0∑i=1N​x(i)=0.

Sample covariance matrix:

Σ=1NXTX∈Rd×d\Sigma = \frac1N X^T X \in \mathbb{R}^{d \times d}Σ=N1​XTX∈Rd×d

Project data onto unit direction vector uuu (uTu=1u^T u = 1uTu=1):

Var(Xu)=1N(Xu)T(Xu)=uT(1NXTX)u=uTΣu\text{Var}(Xu) = \frac1N (Xu)^T (Xu) = u^T \left(\frac1N X^T X\right) u = u^T \Sigma uVar(Xu)=N1​(Xu)T(Xu)=uT(N1​XTX)u=uTΣu

Maximize variance under constraint uTu=1u^T u = 1uTu=1:

L(u,λ)=uTΣu−λ(uTu−1)L(u, \lambda) = u^T \Sigma u - \lambda(u^T u - 1)L(u,λ)=uTΣu−λ(uTu−1)

Take derivative with respect to uuu:

∂L∂u=2Σu−2λu=0  ⟹  Σu=λu\frac{\partial L}{\partial u} = 2\Sigma u - 2\lambda u = 0 \implies \boxed{\Sigma u = \lambda u}∂u∂L​=2Σu−2λu=0⟹Σu=λu​
  • The optimal projection direction uuu is an eigenvector of covariance matrix Σ\SigmaΣ.
  • The variance along uuu is the corresponding eigenvalue λ\lambdaλ.

Algorithm Steps​

  1. Center the data: X~=X−Xˉ\tilde{X} = X - \bar{X}X~=X−Xˉ.
  2. Compute covariance matrix: Σ=1NX~TX~\Sigma = \frac{1}{N} \tilde{X}^T \tilde{X}Σ=N1​X~TX~.
  3. Eigenvalue decomposition: solve Σvi=λivi\Sigma v_i = \lambda_i v_iΣvi​=λi​vi​.
  4. Sort eigenvalues descending: λ1≥λ2≥⋯≥λd\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_dλ1​≥λ2​≥⋯≥λd​, select top kkk eigenvectors:
    W=[v1,v2,…,vk]∈Rd×kW = [v_1, v_2, \dots, v_k] \in \mathbb{R}^{d \times k}W=[v1​,v2​,…,vk​]∈Rd×k
  5. Project data:
    Z=X~W∈RN×k\boxed{Z = \tilde{X} W \in \mathbb{R}^{N \times k}}Z=X~W∈RN×k​

Explained Variance Ratio​

Proportion of total variance preserved by top kkk principal components:

Ratiok=∑i=1kλi∑i=1dλi\text{Ratio}_k = \frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i}Ratiok​=∑i=1d​λi​∑i=1k​λi​​

Connection to SVD​

For zero-centered X~\tilde{X}X~, compute Singular Value Decomposition: X~=USVT\tilde{X} = U S V^TX~=USVT.

Σ=1NX~TX~=1N(VSUT)(USVT)=1NVS2VT\Sigma = \frac1N \tilde{X}^T \tilde{X} = \frac1N (V S U^T)(U S V^T) = \frac1N V S^2 V^TΣ=N1​X~TX~=N1​(VSUT)(USVT)=N1​VS2VT
  • The right singular vectors VVV are the principal direction eigenvectors of Σ\SigmaΣ.
  • Singular values relate to eigenvalues by: λi=si2N\lambda_i = \frac{s_i^2}{N}λi​=Nsi2​​.
  • Direct SVD on X~\tilde{X}X~ avoids calculating XTXX^T XXTX, offering better numerical stability and speed.
import numpy as np

def pca(X: np.ndarray, k: int) -> tuple[np.ndarray, np.ndarray]:
    # 1. Zero-center
    X_centered = X - np.mean(X, axis=0)
    # 2. SVD: X = U S V^T
    U, S, Vt = np.linalg.svd(X_centered, full_matrices=False)
    # 3. Top-k components (V^T rows)
    components = Vt[:k]
    # 4. Project
    Z = np.dot(X_centered, components.T)
    return Z, components
